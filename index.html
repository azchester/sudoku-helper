Sudoku Helper

Blank board with pencil marks. Choose a number status on the left, then click a pencil mark to apply it. Placing a digit clears that mark from the same box, row, and column. When a digit has only one remaining pencil mark in a box, row, or column — or only one mark left in a cell — it is auto-placed as a user entry (black).

Number status

Select a mode (or press H / U / G), then click a pencil mark.

Digit stats

Placed / remaining (of 9). Completes when all nine are filled.

  • Number status (left) — choose Hide mark, Place user, or Place given (H / U / G)
  • Click a pencil mark — apply the selected status
  • Auto-place — sole remaining mark of a digit in a box, row, or column, or a cell with only one mark left, becomes a user entry
  • Conflicts — duplicate filled digits in a box, row, or column highlight in red
  • Hover a digit (board or stats panel) — highlight matching marks and values board-wide
  • Undo / Redo — reverse or re-apply changes (Ctrl/Cmd+Z / Y)
  • New Game — reset to all pencil marks
